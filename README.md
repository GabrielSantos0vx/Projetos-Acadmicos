## 🐾 Pet Amigo

Sistema de terminal em Java que simula o atendimento de um pet shop.

### ✨ Funcionalidades

- Registro de pedidos com vários produtos (ração, brinquedo, shampoo e petisco)
- Desconto automático: 5% para compras acima de R$ 80 e 10% acima de R$ 150
- Promoção no petisco a partir de 5 unidades
- Contribuição opcional de 2% para a campanha de proteção animal
- Fechamento do dia com estatísticas: total de pedidos, valor recebido, brinquedos vendidos, média das contribuições, cliente com maior pedido e percentual de clientes que compraram ração e petisco

### 📸 Exemplo de uso

```
======================
BEM VINDO AO PET AMIGO
======================

Digite seu nome: Ana

Faça seu pedido:
[1] - Pacote de ração:          R$ 25,00
[2] - Brinquedo para animais:   R$ 15,00
...
```

### ▶️ Como executar

1. Clique em **Code → Download ZIP** neste repositório e extraia a pasta.
2. Abra a pasta `Pet Amigo` no **IntelliJ IDEA**.
3. Execute o arquivo `PetAmigo.java`.
